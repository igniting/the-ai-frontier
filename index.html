    A compiler you can watch work
    
            
    Lumen is a small, statically typed functional language. Everything on this page runs in your browser. The compiler is about 3,500 lines of dependency-free JavaScript. It infers every type, checks that every match is exhaustive, and emits a WebAssembly binary byte by byte. Programs that allocate carry their own garbage collector inside that binary.
    
            
    Pipeline
    
            
      
              
    • Lexer and parserRecursive descent with precedence climbing; list literals and |> are desugared.
      src/lexer.js, parser.js · 526 lines
      • 
              
    • Type inferenceHindley–Milner with level-based generalization. Top-level functions are grouped into strongly connected components so they can appear in any order.
      types.js, typecheck.js · 721
      • 
              
    • ExhaustivenessMaranget’s usefulness algorithm. It reports a concrete value that no arm handles, and warns about unreachable arms.
      exhaustive.js · 157
      • 
              
    • LoweringA-normal form, closure conversion, lambda lifting, pattern-match compilation and type-directed root elision.
      lower.js · 355
      • 
              
    • Code generationShadow-stack frames for GC roots, return_call for tail calls, static closures for capture-free functions.
      codegen.js · 362
      • 
              
    • RuntimeBump allocator, Cheney copying collector with growing semispaces, structural equality and ordering, strings. Written as raw wasm instructions.
      runtime.js · 332
      • 
              
    • Binary encoderLEB128, sections, label-depth resolution, a name section, and the WAT printer you see in the WebAssembly tab.
      wasm.js · 342
      • 
              
    • Reference interpreterAn independent tree-walking evaluator over the typed AST, used as the oracle for differential testing.
      interp.js · 242

    How it is verified
    
            
    Golden tests cover every example. Semantic tests run each program three ways. The differential fuzzer (the Fuzzer tab) has checked more than 11,000 random programs with no disagreement. Mutation testing confirms that the fuzzer catches 16 of 16 deliberately injected compiler bugs.
    
            
    The language in one breath
    
            
    31-bit integers that wrap around, booleans, byte strings, tuples, and generic algebraic data types. Pattern matching with guards and nested patterns. First-class functions and closures. Structural == and < on any type except functions. A prelude of list, option and string functions, itself written in Lumen. Run it locally with npm run serve, or use the CLI: node bin/lumen.js run examples/huffman.lm --stats.
